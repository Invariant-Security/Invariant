# CLAUDE.md

This file exists because Claude Code looks for `CLAUDE.md` by filename
convention. The canonical, current, detailed project context — philosophy,
architecture, what's actually implemented, setup, demo, known gotchas — is
`AGENTS.md` at the repo root. Read that first.

`INVARIANT_PRD.md` remains the source of truth for intended design and
architecture decisions (~50 numbered sections) when a design question comes
up — confirm against the code what's actually implemented before assuming a
described behavior runs today.
